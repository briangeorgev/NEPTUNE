# NEPTUNE — TRIDENT Website

Three-page static website for the NEPTUNE academic project.

## Pages
- `index.html` — NEPTUNE home page
- `trident.html` — TRIDENT product page
- `how-to-use.html` — how to use the bottle

## Files
- `style.css` — shared styling
- `script.js` — mobile navigation and reveal animations
- `assets/` — supplied NEPTUNE logo and product images

## GitHub Pages
1. Create a GitHub repository.
2. Upload every file and the `assets` folder, keeping the folder structure unchanged.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save. GitHub will provide the Pages URL.

No build step or backend is required.
